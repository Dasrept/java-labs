# Лабораторная работа 3: Интерфейсы и полиморфизм

Условие: [`assignments/lab03-polymorphism.md`](../assignments/lab03-polymorphism.md).

Из корня репозитория запустите:

```bash
./mvnw -pl lab03 test
```

Windows PowerShell: `.\\mvnw.cmd -pl lab03 test`.

Основной код размещайте в `src/main/java/edu/course/lab03/`, тесты — в `src/test/java/edu/course/lab03/`. В начале каждого Java-файла укажите `package edu.course.lab03;`.

Модуль независим от остальных лабораторных. Если нужны модели из предыдущей работы, перенесите и при необходимости адаптируйте только нужные классы в этот модуль. Начальная успешная сборка не является выполнением задания: создайте реализацию и собственные тесты по условию.

## Инварианты и устройство

- Цена не может быть отрицательной; процентная скидка задается в диапазоне от 0 до 100 включительно.
- `PriceCalculator` использует `DiscountPolicy`, полученную через конструктор, и не создает конкретную политику самостоятельно.
- Стратегии нормализации принимают непустые массивы только с конечными числами и возвращают новые массивы, не меняя входные данные.
- `FeatureProcessor` получает `NormalizationStrategy` через конструктор, поэтому способ обработки можно заменить без изменения процессора.
- Min-max-нормализация постоянного вектора возвращает нули; mean-centering вычитает среднее; дополнительная Z-score-нормализация использует стандартное отклонение генеральной совокупности.
