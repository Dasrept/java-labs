# Лабораторная работа 2: Классы и инкапсуляция

Условие: [`assignments/lab02-domain-model.md`](../assignments/lab02-domain-model.md).

Из корня репозитория запустите:

```bash
./mvnw -pl lab02 test
```

Windows PowerShell: `.\mvnw.cmd -pl lab02 test`.

Основной код размещайте в `src/main/java/edu/course/lab02/`, тесты — в `src/test/java/edu/course/lab02/`. В начале каждого Java-файла укажите `package edu.course.lab02;`.

Модуль независим от остальных лабораторных. Если нужны модели из предыдущей работы, перенесите и при необходимости адаптируйте только нужные классы в этот модуль. Начальная успешная сборка не является выполнением задания: создайте реализацию и собственные тесты по условию.

## Инварианты моделей

- `BankAccount`: баланс неотрицателен; пополнение и списание принимают только положительную сумму; списание не превышает остаток.
- `DataSample`: идентификатор и метка не `null` и не пусты; статус задан; массив признаков непустой, содержит только конечные числа и копируется при создании и выдаче. Среднее считается по всем признакам.

## Дополнительная часть

`SampleId` — record-значение: он неизменяем, а два идентификатора с одинаковым текстом равны по значению. `DataSample.withId` принимает такой идентификатор.

`normalizedFeatures()` возвращает новый массив с min-max нормализацией в диапазон `[0, 1]`; при одинаковых признаках результат состоит из нулей. Исходное наблюдение не изменяется.
